# ── EchoCoach backend — PRODUCTION/DEPLOY runtime deps ────────────────────────
# This is the dependency set the deployed container installs. It deliberately
# EXCLUDES the heavy ML stack (torch, transformers, kokoro, librosa, soundfile)
# because:
#   • Live conversation only needs: Gemini/Groq (LLM) + Groq Whisper (STT) +
#     edge-tts→miniaudio (TTS). All lightweight, all cloud or pure-Python.
#   • The post-session Wav2Vec2 phoneme report imports torch lazily and is wrapped
#     in try/except — it simply no-ops if torch isn't present, so the app runs fine.
# Result: a ~150 MB image that builds in ~1 min instead of a 2.5 GB / 10-min build.
#
# For full local dev WITH phoneme analysis, use requirements.txt instead.
